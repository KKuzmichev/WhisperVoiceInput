# SSH + PulseAudio forwarding: удалённый сервер с микрофоном клиента

## Контекст
Текущая архитектура: voiceinput использует `sounddevice` (PortAudio) для захвата микрофона. На Linux PortAudio по умолчанию использует PulseAudio. Нужно перенаправить аудиоустройство клиента (macOS) на удалённый Linux-сервер.

**Код менять не нужно** — PulseAudio forwarding решается на уровне системы через SSH-туннель + переменная окружения `PULSE_SERVER`.

## Архитектура

```
[Клиент (macOS)]                    [Сервер (Linux)]
PulseAudio ← CoreAudio              voiceinput → PortAudio → PulseAudio ← SSH tunnel
    ↕ (port 4713)                        ↕ (port 4713)
    ←←←←←← SSH -R 4713 ←←←←←←←←←←←←←←
```

## План

### 1. Клиент (macOS): запуск PulseAudio с TCP

Установка и запуск PulseAudio на macOS (через Homebrew):
```bash
brew install pulseaudio
```

Запуск с поддержкой TCP (на порту 4713):
```bash
pulseaudio --load="module-native-protocol-tcp auth-ip-acl=127.0.0.1" --exit-idle-time=-1
```

Проверка: `pactl info` — должен показать PulseAudio сервер.

### 2. SSH-туннель с пробросом PulseAudio

С клиента подключиться к серверу с обратным туннелем:
```bash
ssh -R 4713:localhost:4713 user@server
```

Это пробросит порт 4713 клиента на `localhost:4713` сервера.

### 3. Сервер (Linux): настройка PulseAudio клиента

На сервере должен быть установлен PulseAudio client:
```bash
# Debian/Ubuntu
sudo apt install pulseaudio

# Arch
sudo pacman -S libpulse
```

Проверить подключение:
```bash
PULSE_SERVER=tcp:localhost:4713 pactl list sources short
# Должен показать источник микрофона клиента
```

### 4. Запуск voiceinput на сервере

```bash
PULSE_SERVER=tcp:localhost:4713 voiceinput --model=base --language=ru
```

PortAudio (sounddevice) автоматически подхватит `PULSE_SERVER` и будет использовать микрофон клиента через SSH-туннель.

## Верификация

1. Клиент: запустить PulseAudio, проверить `pactl info`
2. Поднять SSH-туннель `ssh -R 4713:localhost:4713 user@server`
3. На сервере: `PULSE_SERVER=tcp:localhost:4713 pactl list sources short` — должен увидеть микрофон клиента
4. Запустить `PULSE_SERVER=tcp:localhost:4713 voiceinput` на сервере
5. Двойное нажатие Ctrl → говорить в микрофон клиента → текст появится в терминале сервера
